# Portfolio V2

## About
This is a revamp of my portfolio website. Originally built with Vite and hosted on GitHub pages, I decided to take the opportunity to migrate this project to Vercel so I could utilize the Next.js package. The platform wasn't exactly the issue, though. It's just that the old version had a messy codebase written by someone who didn't really have any idea how React, Tailwind, and TypeScript works (me :P). After gaining enough extensive knowledge on the tech stack in question, I decided to make the website my own and rewrite everything from scratch; with modularity, consistency, and layout responsiveness.

## Tech Stack
- Next.js
- React
- Tailwind CSS
- TypeScript
- JavaScript
